# FLDO M1 — Windows 프로토타입

기존 GameMaker 게임을 기준으로 제작한 Unity 1차 프로토타입의 실행 빌드 배포 페이지입니다. 정식 상업 출시본이 아닙니다.

[최신 M1 빌드 다운로드](https://github.com/Noskang/FLDO-Releases/releases/tag/m1-20261001-014527)

전체 ZIP을 풀고 `FLDO_Unity.exe`를 실행해 주세요. exe만 별도로 복사하면 실행되지 않습니다. Windows x64 개발 빌드이며 Build ID는 `20261001-014527`, 제품 버전은 `0.16.0-ia016`입니다. 체크섬은 `SHA256SUMS.txt`로 확인할 수 있습니다.

## 확인 범위

M1 기본 작동은 사용자 플레이 검수를 거쳤습니다. 스폰 SFX 청취, 최종 추가 입력 안내의 위치/크기 인상, 마지막 종료·재개방 확인은 별도 대기입니다. 이동 중 화면 중앙 울렁거림(F02)은 보류 상태입니다. 이번 배포 정리는 게임 재빌드나 새 인수 검사가 아닙니다.

## 자료와 역할

원작 게임·아트는 원작 제작자와 각 권리자의 자료입니다. 사용자는 제품 기획·규칙 결정·플레이 검수, ChatGPT는 상담·프롬프트 보조, Codex는 분석·구현·검사를 담당했습니다. 이 페이지는 실행 빌드와 배포 안내만 포함하며 제작 소스·기획 Excel·내부 기록은 공개하지 않습니다.

제3자 자료가 포함되어 있으므로 이 저장소가 게임 자산에 대한 포괄적인 재배포·상업 사용 허락을 부여하지 않습니다. 별도의 오픈소스 라이선스를 부여하지 않았습니다.

## 변경 제안

열람과 다운로드는 공개됩니다. 원본 저장소의 변경·병합 권한은 소유자에게 있습니다. 외부 제안은 검토 절차를 거쳐야 하며 임의의 자동 병합을 하지 않습니다. 빌드 바이너리는 Git 이력에 넣지 않고 Release에만 첨부합니다.
